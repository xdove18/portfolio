# Портфолио — Лиза Иванова

Сайт-портфолио продуктового дизайнера. React + Vite.

---

## Как запустить сайт у себя на компьютере

Откройте **PowerShell** в папке `portfolio` и выполните:

```bash
npm run dev
```

Появится строчка `Local: http://localhost:5173/` — откройте этот адрес
в браузере. Сайт обновляется сам, как только вы сохраняете файл.

Остановить сервер: `Ctrl + C` в том же окне.

## Что где лежит (самое важное)

### Файлы, которые вы будете править чаще всего

| Файл | Что в нём |
|------|-----------|
| `src/data/site.js` | Имя, возраст, город, телеграм, тексты «обо мне», опыт работы |
| `src/data/projects.js` | Всё содержимое кейсов: задача, гипотезы, конкуренты, результаты |
| `src/data/stack.js` | Список программ в разделе «стек» |
| `src/data/toys.js` | Игрушки в автомате и подписи к ним |
| `src/styles/variables.css` | Все цвета и размеры сайта |
| `index.html` | Заголовок сайта в поиске Google и превью ссылки |

**Правило одно:** текст всегда внутри кавычек, запятая в конце строки нужна.

```js
name: "Лиза Иванова",     ← правильно
name: Лиза Иванова        ← сломается
```

Если сайт «сломался» после правки — вернитесь и проверьте кавычки и запятые.

### Куда класть картинки

Все картинки лежат в папке `public/images/`:

```
public/images/
├── me.webp                   ← ваше фото в разделе «обо мне»
└── projects/
    ├── smart-size/           ← экраны кейса «Умный размер»
    │   └── thumb/            ← их уменьшенные копии
    ├── checkout/             ← экраны кейса «Оптимизация чекаута»
    │   └── thumb/
    └── habits/               ← экраны кейса HabitFlow
        └── thumb/
```

**Про папки `thumb/`.** У каждого экрана две версии: полная и
уменьшенная. Мелкую показывает галерея и карточки на главной,
полная открывается только по клику. Благодаря этому страница
с двадцатью экранами весит в разы меньше.

Чтобы добавить экран в кейс:

1. Положите файл в нужную папку.
2. Запустите пересчёт картинок (см. ниже) — он сам сделает
   уменьшенную копию и переведёт файл в лёгкий формат.
3. Допишите путь к нему в `src/data/projects.js`.

### Как пережать картинки

Если вы добавили новые фото, выполните в папке `portfolio`:

```bash
npm run images
```

Команда переведёт новые PNG и JPG в формат WebP (тот же вид,
вес в 6–9 раз меньше) и создаст уменьшенные копии в `thumb/`.
Оригиналы в папках «кейс 1/2/3» на рабочем столе не трогаются —
они остаются нетронутыми на случай, если понадобятся снова.

### Резюме

Положите файл `resume.pdf` в папку `public/` — кнопка «скачать резюме»
сразу заработает.

## Что осталось дописать

Найдите поиском (`Ctrl + F`) слово **ЗАПОЛНИТЬ** в файле
`src/data/projects.js`. Помечены места, где нужен ваш текст:

- гипотезы кейса HabitFlow и выводы по ним;
- плюсы и минусы конкурентов Fabulous и Finch;
- метрики результата HabitFlow.

Весь этот текст есть в вашем макете `страница для привычек.png` —
осталось перенести его в файл.

## Структура кода

```
src/
├── components/       — блоки сайта
│   ├── Header/       — шапка с меню
│   ├── Hero/         — первый экран с цветками
│   ├── About/        — «обо мне»
│   ├── Projects/     — карточки-папки проектов
│   ├── Stack/        — плитки с программами
│   ├── Footer/       — чёрный подвал с лепестками
│   ├── ClawMachine/  — автомат с игрушками
│   ├── Case/         — блоки страницы кейса
│   ├── Flower/       — цветок (нарисован кодом)
│   └── icons/        — мелкие значки
├── pages/            — страницы целиком
├── data/             — ВСЕ ТЕКСТЫ САЙТА
├── styles/           — цвета, общие стили, анимации
└── hooks/            — вспомогательная логика
```

У каждого блока рядом лежит свой файл стилей `.module.css`.
Например, шапка — это `Header.jsx` (что показать) и
`Header.module.css` (как это выглядит).

## Как выложить сайт в интернет (Vercel, ~10 минут)

1. Заведите аккаунт на [github.com](https://github.com) и создайте
   пустой репозиторий, например `portfolio`.
2. Загрузите туда содержимое папки `portfolio` (можно перетащить файлы
   прямо в браузере: **Add file → Upload files**).
   Папку `node_modules` загружать **не нужно** — она большая и не требуется.
3. Зайдите на [vercel.com](https://vercel.com), войдите через GitHub.
4. Нажмите **New Project** → выберите свой репозиторий → **Deploy**.
5. Через пару минут получите ссылку вида `portfolio.vercel.app`.

Дальше можно подключить свой домен: **Project Settings → Domains**.

В проекте уже лежит файл `vercel.json` — он нужен, чтобы страницы кейсов
открывались по прямой ссылке. Не удаляйте его.

## Если что-то пошло не так

**Сайт не запускается, ошибка про модули** — выполните `npm install`.

**Белый экран** — откройте консоль браузера (`F12` → вкладка Console),
там будет написано, в каком файле ошибка. Чаще всего это забытая
кавычка или запятая в файлах из папки `src/data/`.

**Автомат больше не появляется** — он показывается один раз за визит.
Закройте вкладку и откройте сайт заново.
